Conheça o VERTEX

Uma proposta de mobilidade assistiva que explora a interação entre interfaces cérebro-máquina e tecnologia.

NOSSA MISSÃO

Mais autonomia, novas possibilidades.

O projeto acadêmico investiga o desenvolvimento de uma cadeira de rodas controlada por ondas cerebrais através de uma interface cérebro-máquina, com uma plataforma para acompanhar informações e facilitar a experiência de uso.
